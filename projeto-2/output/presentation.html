Motivação: os labels automáticos falharam

Problema anterior

  • Classes por resolução, pasta e aspect ratio.
  • Capturas, wallpapers e fotos pessoais se misturavam.
  • has_people tinha falsos positivos/negativos visíveis.

Novo princípio

  • Primeiro descobrir grupos visuais.
  • Depois inspecionar exemplos reais.
  • Só então criar labels humanos para classificação.

O número de subclusters varia por macrocluster: G00_S00, G00_S01, G01_S00...

Escolha de K por métricas

K global

  • Busca em K=2..80.
  • Rejeita clusters pequenos demais.
  • Ranking por score composto.

Métricas

  • Silhouette ↑
  • Davies-Bouldin ↓
  • Calinski-Harabasz ↑
  • Inertia / elbow
  • Balanceamento dos clusters

Clustering hierárquico

Depois de escolher K_global, cada macrocluster recebe sua própria busca de K_sub=2..16.

G00 → K_sub = 3
G01 → K_sub = 11
G02 → K_sub = 2
G03 → K_sub = 7

Isso evita forçar a mesma granularidade em grupos visuais naturalmente diferentes.

Como um cluster vira texto?

Não fazemos

Não existe inversa confiável do embedding CLIP para texto.

Fazemos

  • imagens próximas ao centroide;
  • contact sheets;
  • top pastas/metadados;
  • anotação humana.

Interface de anotação

Acessível

  • fontes grandes;
  • alto contraste;
  • botões grandes;
  • atalhos de teclado;
  • imagens grandes.

Sincronizada

  • autosave em tempo real;
  • cluster_annotations.json incremental;
  • campos: label, usar/descartar/dividir, notas.

Dataset supervisionado final

O classificador só usa subclusters aprovados manualmente:

{
  "G07_S02": {
    "label_final": "desktop_screenshots",
    "usable_for_classification": true,
    "needs_split": false
  }
}

Split estratificado 70/15/15 e baseline MLP sobre embeddings CLIP.

Limitações e próximos passos

  • CLIP organiza similaridade visual, não semântica perfeita.
  • A qualidade final depende da anotação humana dos subclusters.
  • UMAP melhora visualização se instalado; PCA é fallback sempre disponível.
  • VAE fica como extensão futura, não requisito do pipeline inicial.
