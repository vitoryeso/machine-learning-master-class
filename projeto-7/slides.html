Redes RBF

Rede de funções de base radial construída do zero (numpy) para um problema real: classificação binária da coleção pessoal de imagens (features CLIP), 3 tarefas. Foco do enunciado: como a escolha dos centros afeta a classificação.

gaussianas

camada oculta de funções radiais

3 estratégias

centros: aleatório · K-means · subset

least-squares

saída resolvida em forma fechada

Método: a rede RBF

φⱼ(x) = exp( −‖x − cⱼ‖² / 2σ² )
ŷ = Σⱼ wⱼ·φⱼ(x) + b
  • x — entrada: vetor de features CLIP da imagem (512-d).
  • cⱼ — os centros (protótipos); aqui escolhidos por K-means/aleatório/subset.
  • σ — largura da gaussiana (calibrada pela mediana das distâncias ponto→centro).
  • φⱼ(x) — ativação: ~1 se x perto de cⱼ, →0 se longe.
  • wⱼ, b — pesos do readout linear (mínimos quadrados).
  • ŷ — saída; classe 1 se ŷ ≥ 0.5.

Como os centros particionam o plano

  • Cada estrela é um centro cⱼ; em volta dele a gaussiana "acende", e a soma ponderada desenha a fronteira.
  • A escolha dos centros importa (multi-seed): K-means vence de forma robusta (intervalos não se sobrepõem). Já aleatório vs subset é empate/ruído — os ±desvios se sobrepõem e a ordem inverte por tarefa.
  • Mais centros → melhor, mas com retorno decrescente — cobrem melhor o espaço.
