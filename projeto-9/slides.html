MLP construído do zero (numpy, backprop manual) para classificar a coleção pessoal de imagens (features CLIP) em 3 tarefas. Desempenho medido em full-dim; o plano 2D (PCA) ilustra como os neurônios particionam o espaço.

forward + backprop na mão, sem framework

3 tarefas

pessoa, screenshot×foto, macro-grupo

MSE vs CE

duas perdas comparadas

Método: MLP do zero

Arquitetura

z = aᵀW + b
oculta: relu/tanh
saída:  sigmoid → p

Backprop manual: δ_saída = (p−y) (CE) ou 2(p−y)·p(1−p) (MSE); propaga com act'.

O que ablar

  • Perda: MSE vs cross-entropy.
  • Arquitetura: 0 → 128 neurônios ocultos.
  • Viz 2D: cada neurônio = uma reta; a combinação = a fronteira não-linear.
  • a — entrada da camada; W, b — pesos e viés (aprendidos).
  • z = aᵀW+b — pré-ativação; p — saída sigmoid.
  • y — rótulo real; δ_saída — erro na saída (p−y).
  • act' — derivada da ativação (relu/tanh) na backprop.

Como os neurônios particionam o plano

  • Cada um dos 4 neurônios ocultos é uma reta (tracejada); a saída combina-as numa região não-linear que isola o grupo.
  • MSE ≈ CE em magnitude, mas no multi-seed a CE fica consistentemente um fio acima onde há sinal (0.965±0.001 vs 0.961±0.003 no macro — bandas não se sobrepõem).
  • Camada oculta ajuda um pouco de verdade: no multi-seed a logística (0 ocultas) fica reprodutivelmente ~1 ponto ABAIXO (F1 0.954±0.002 vs 0.965±0.003 com oculta, ~3σ). O single-seed (0.956≈0.967) mascarava isso. Ainda assim o ganho é pequeno: as features CLIP já são quase linearmente separáveis.
