ANN/MLP: Fronteiras Não-Lineares

MLP construído do zero (numpy, backprop manual) para um problema real: classificação binária da coleção pessoal de imagens (features CLIP), em 3 tarefas. Desempenho medido em full-dim; o plano 2D (PCA) ilustra como os neurônios particionam o espaço.

numpy

forward + backprop na mão, sem framework

3 tarefas

pessoa, screenshot×foto, macro-grupo

MSE vs CE

duas perdas comparadas

Método: MLP do zero

Arquitetura

z = aᵀW + b
oculta: relu/tanh
saída:  sigmoid → p

Backprop manual: δ_saída = (p−y) (CE) ou 2(p−y)·p(1−p) (MSE); propaga com act'.

O que ablar

  • Perda: MSE vs cross-entropy.
  • Arquitetura: 0 → 128 neurônios ocultos.
  • Viz 2D: cada neurônio = uma reta; a combinação = a fronteira não-linear.

Como os neurônios particionam o plano

  • Cada um dos 4 neurônios ocultos é uma reta (tracejada); a saída combina-as numa região não-linear que isola o grupo.
  • MSE ≈ CE aqui (F1 0.962 vs 0.965) — a CE converge um pouco mais rápido.
  • 0 camadas ocultas (=logística) já dá F1 0.956: as features CLIP são quase linearmente separáveis, então a não-linearidade do MLP agrega pouco em full-dim. A não-linearidade importa mais no plano 2D comprimido.
