K-Means do zero sobre embeddings de imagens

Minha coleção pessoal de imagens (fotos, wallpapers, arte gerada por IA, screenshots, memes) não tem rótulos. Este projeto implementa K-Means (Lloyd + K-means++) do zero em Rust para descobrir uma taxonomia visual a partir de embeddings CLIP — não-supervisionado, sem verdade externa.

K-means++ (2007)

1º centroide ao acaso; os seguintes com prob. ∝ D² (distância² ao centroide mais próximo). Espalha a inicialização, evita mínimos locais ruins.

Lloyd (iteração)

Repete até convergir: (1) atribui cada ponto ao centroide mais próximo (Voronoi em 512-d); (2) recalcula centroides = média dos pontos. 3 runs/K.

PCA 2D — por cluster (K-means)

Mesma projeção — por pasta: sem correspondência clara

  • Cluster 0 (26,6%) "arte digital": wallpapers/IA, paisagem-quadrado.
  • Cluster 1 (24,6%) "fotos pessoais": 81% iPhone, 70% retrato, mediana 8,5MB.
  • Cluster 2 (28,8%) "pessoas/retratos": 50% people, 75% retrato, mediana 5,9MB.
  • Cluster 3 (20,0%) "screenshots": 57% iPhone, arquivos pequenos (241KB).

Insight: CLIP agrupou por semântica visual, não metadados — iPhone aparece nos 4 clusters. Limitações: silhouette baixo, PCA 2D perde info de 512-d. Próximos passos: UMAP/DBSCAN, DINOv2.
