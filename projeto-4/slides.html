Formulação e gradiente

Modelo + custo

p = sigmoid(wᵀx + b) = 1/(1+e^−z)
BCE: L = −(1/N)Σ[y·ln p + (1−y)·ln(1−p)]

Sigmoid em 2 ramos (z≥0 / z<0) p/ evitar overflow.

Gradiente (a beleza)

∂L/∂w = (1/N)·Σ (p − y)·x
∂L/∂b = (1/N)·Σ (p − y)

A chain-rule BCE∘sigmoid cancela → sobra (p−y). Treino: lr=0.1, 1000 épocas.

  • x — features; z = wᵀx+b — score linear.
  • p — probabilidade prevista (classe 1 se p ≥ 0.5).
  • w, b — pesos e viés (o que se treina).
  • N — nº de exemplos; y — rótulo real (0/1).

Conclusão

  • Implementação do zero correta: 96.7% de teste confirma o gradiente analítico.
  • Erro de teste 3.33% ≈ limite de Bayes 3.57% (Φ(−√13/2)) → o gargalo é o ruído do problema, não o modelo.
  • Modelo linear → fronteira é reta; dados não-lineares exigiriam features polinomiais.
  • Melhorias: regularização L2 (+λ‖w‖²), critério formal de parada, mini-batch para escala.
