Método: SVM-RBF

K(x, xᵢ) = exp( −γ·‖x − xᵢ‖² )
f(x) = Σᵢ αᵢ·yᵢ·K(x, xᵢ) + b
ŷ = sinal( f(x) )

K mede a similaridade gaussiana entre x e cada vetor de suporte xᵢ; f(x) soma essas similaridades ponderadas (αᵢ·yᵢ) e o sinal decide a classe. γ ajusta o alcance do kernel; C, a tolerância a erro.

  • x — entrada (features CLIP).
  • xᵢ — vetores de suporte (na margem).
  • K — kernel RBF (similaridade gaussiana).
  • γ — alcance do kernel: alto=local, baixo=suave.
  • αᵢ, yᵢ — peso e rótulo do SV.
  • C — regularização (margem × erro).
  • ŷ — sinal de f(x).

Vetores de suporte e γ

  • Os círculos são os vetores de suporte — só eles definem a fronteira; o resto dos pontos é irrelevante.
  • No plano 2D comprimido as classes se sobrepõem, então quase um quarto dos pontos vira vetor de suporte (faixa larga de incerteza).
  • γ é crítico: γ alto (0.1) faz o kernel só "ver" o ponto vizinho → colapsa para F1 0.09; γ baixo/scale generaliza (0.95). C importa bem menos aqui. (Robusto no multi-seed: γ ~200× o std; SVM > baseline nas 3 tarefas.)
