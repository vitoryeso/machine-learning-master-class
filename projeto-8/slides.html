SVM com kernel gaussiano para classificação binária da coleção pessoal de imagens (CLIP), 3 tarefas. Foco do enunciado: os vetores de suporte como "centros" efetivos e o efeito de C e γ.

Método: SVM-RBF

K(x, xᵢ) = exp( −γ·‖x − xᵢ‖² )
f(x) = Σᵢ αᵢ·yᵢ·K(x, xᵢ) + b
ŷ = sinal( f(x) )
  • x — entrada (features CLIP da imagem).
  • xᵢ — os vetores de suporte: pontos de treino que tocam a margem.
  • K — kernel RBF: similaridade gaussiana entre x e xᵢ.
  • γ — largura do kernel: alto = influência local; baixo = suave.
  • αᵢ, yᵢ — peso e rótulo (±1) de cada vetor de suporte.
  • C — regularização: troca margem larga × erros no treino.
  • ŷ — classe pelo sinal de f(x).

Vetores de suporte e γ

  • Os círculos são os vetores de suporte — só eles definem a fronteira; o resto dos pontos é irrelevante.
  • No plano 2D comprimido as classes se sobrepõem, então quase um quarto dos pontos vira vetor de suporte (faixa larga de incerteza).
  • γ é crítico: γ alto (0.1) faz o kernel só "ver" o ponto vizinho → colapsa para F1 0.09; γ baixo/scale generaliza (0.95). C importa bem menos aqui.
